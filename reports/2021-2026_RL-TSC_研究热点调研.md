## 一、核心结论

近五年 RL-TSC 的主线是 **「单点可控 → 路网可协同 → 跨场景可迁移 → 实际可落地」**。方法侧依次经历价值型 DQN 系 → Actor-Critic / 策略梯度系 → 多智能体 CTDE + 图与注意力网络 → Transformer 与序列决策 → 泛化 / 元学习 / 基础模型；评价重心则从「仿真中比固定配时降低多少延误」转向「换城市还能不能用、传感器坏了还稳不稳、决策能不能解释、能不能真正装到路口」。

三条结构性判断：

1. **范式叠加而非替代**：多智能体并未淘汰单智能体方法，而是在其上叠加协同、迁移与安全约束；2021 年论文多假设「路口同构、需求固定」，2026 年前沿默认「异构、跨城、有扰动、感知有缺失」。
2. **目标函数扩容**：奖励从单一延误 / 排队，扩展为效率—安全—排放—公平的多目标或带约束优化；安全屏蔽、动作掩码、规则兜底成为混合架构的常见组件。
3. **证据标准在抬高但仍有缺口**：SUMO / CityFlow 仍是事实标准仿真平台，路网高度集中于杭州、济南、纽约、摩纳哥、卢森堡等基准；真实部署证据直到 2025–2026 年才出现带量化结果的试点报告，且多为「约束式在线控制」而非全自主控制。

### H1 · 多智能体协同与 CTDE（贯穿全程的主干）

单点 RL 只能得到局部最优，而相邻路口的耦合会决定绿波是否成立。2021 年后研究几乎默认多智能体设置，**集中训练—分散执行（CTDE）** 成为解决「训练可见全局、执行仅见本地」矛盾的标准框架。

- 值分解 / 全局 critic：时空图注意力 + 值分解处理异构路口（Bie 等 2024）、反事实多智能体 actor-critic（Song 等 2024）。
- 参数服务器 / 联邦式：两层协同 RL 由本地上传经验、中央回传参数（Ren 等 2024）；联邦 DRL 周期聚合本地模型（Li 等 2025）。2025 年底出现「半集中式 CTDE」的进一步细分（arXiv:2512.04653）。
- 规模扩展：区域划分 + 分层 RL（FMA2C、GPLight、ReginLight 等），延续「千路口级」实验传统（纽约 2,510 个信号灯）。
- 当前难点：异构路口（相位数、车道数不同）导致策略难以共享；通信开销与全局协调强度之间存在明确的权衡（Springer 2026 系统综述将其列为核心张力）。

### H2 · 从图神经网络到 Transformer 的时空表征

这是五年中方法更新最快的一条线。

- 静态图（2021–2022）：GCN/GAT 把路网当图，代表如 CoLight 的图注意力、IHG-MA 的异构图、GraphLight。
- 动态时空图（2022–2025）：DynSTGAT 用动态注意力刻画流量与拓扑的时间演化；后续针对「极端拥堵会改变有效拓扑」提出动态时空记忆增强。中文核心期刊在此方向有集中产出——《中国公路学报》2024 年王福建等用 GRU 提取时变特征 + 图注意力层递融合 + 路口重要度重构状态空间，在实际路网仿真中低 / 中 / 高流量下平均排队长度分别下降 13.74% / 5.03% / 6.30% 以上。
- Transformer 与序列决策（2023–2025）：Transformer Light 处理非平稳流；Decision Transformer 类控制器把 TSC 表述为「给定历史与目标回报生成动作序列」；教师—学生 Transformer 提升样本效率；HydraLight 等用全局上下文时空图 Transformer 处理规模问题。
- 趋势：从「如何编码空间」转向「如何处理非平稳与长程依赖」；副作用是模型变重，与边缘实时推理要求形成张力。

### H3 · 泛化、迁移与 sim-to-real（2024 年后的头号新热点）

跨城市 / 跨路网失效是落地的关键瓶颈，因此评价口径从「单场景指标」升级为「零样本 / 少样本迁移后还剩多少性能」。

- 可迁移表征：Dualight（2023）、CrossLight（2024）、X-Light（2024，Transformer + 元 RL 跨城零样本）、CoSLight（2024）、GeneraLight、AttendLight、MetaLight 系元学习路线。
- 感知缺失鲁棒性：BlindLight 针对「盲路口」、MalLight / DiffLight 针对传感器缺失；RGLight（IEEE Open J. ITS, 2023）用归纳图 + 分布 RL（IQN），在 60% 传感数据缺失下仍保持可用，并在曼哈顿 / 卢森堡路网上做零样本迁移。
- 仿真到现实：CDC'23 的 UGAT 用不确定性量化的 grounded action transformation；AAAI'24 的 *Prompt to Transfer* 借助 LLM 刻画天气、路型对动力学的影响以校准仿真策略。
- 2026 年新动向：开始用**真实小时级流量数据**（而非合成需求）检验跨工作日 / 周末、需求扰动的泛化（arXiv:2606.22108）。

### H4 · 多目标、安全约束与公平

- 奖励设计：从延误 / 排队单目标，扩展到效率、安全、脱碳的加权多目标（Zhang 等 2024, *Accident Analysis & Prevention*）；2025 年有工作用 PPO/A2C/DQN 同时评估延误、安全与 CO₂。
- 安全硬约束：SafeLight（AAAI 2023）把「无冲突」写进方法层；动作屏蔽、规则盾、最小绿灯时间等护栏成为混合架构标配。
- 公平与以人为本：2025–2026 年出现面向低需求方向「饥饿」问题的队列均衡惩罚、动作分支 DRL 的公平性控制（*Communications in Transportation Research* 2025、*EAAI* 2026），以及混合自主性下 HDV 与 CAV 的公平比指标。
- 韧性：把事故、极端天气、通信中断、应急车辆优先直接嵌入训练场景，从「抗拥堵」扩展到「抗扰动」。

### H5 · 车路协同（V2X / CAV）与混合交通

- 信号—车辆联合控制：不单控灯，同时给 CAV 建议速度 / 轨迹（CVLight、CoTV、EMVLight 应急车辆优先、DRL-TP3）。
- 混合交通（人工驾驶 + 自动驾驶共存）：2025 年 arXiv:2511.02217 用 GAT + SAC 同时优化信号与车辆运动并报告公平比；arXiv:2512.11247 用分层多目标 RL + 战略路由处理效率 / 公平 / 安全；arXiv:2512.06645 直接研究碰撞率影响因素。
- 国内侧重：中文核心期刊在 CAV 与信号交叉口耦合方向投入显著，例如《中国公路学报》2025 年秦严严等的 CAV 生态驾驶（TD3 + 随机环境泛化）、2025 年刘美岐等的无信号路网 CAV 轨迹优化（PPO）。这些属于本报告边界的邻近方向，但反映国内「车路云一体化」的问题设定。
- 共性局限：多数方法隐含较高 CAV 渗透率与密集通信，在低渗透率、数据稀缺地区的可迁移性存疑（arXiv:2606.22108 明确列为三大空白之一）。

### H6 · 基础模型、可解释性与真实部署

- LLM 介入的两条早期范式（Traffic-R1 论文归纳）：**LLM Explainer**（把 RL 策略 verbalize 为自然语言理由）与 **LLM Assistant**（常规由 RL 控制，OOD 事件才咨询 LLM）；二者分别受限于底层策略性能上限与推理延迟。
- 基础模型路线（2025–2026）：LLMLight（KDD 2025）→ Traffic-R1（arXiv:2508.02344, 2025；已被 ACL 2026 接收）：3B 参数、零样本跨路网、边缘可部署、可解释，报告称已服务 55,000+ 驾驶员 / 日、平均排队降幅 >5%；VLMLight（arXiv:2505.19486）用视觉语言元控制器在常规 / 安全关键场景间切换；Traffic-VL（arXiv:2611.06353, 2026-11）用 8B VLM 直接从多视角监控图像 + 自然语言相位描述端到端决策，报告了 10 个互联路口为期三周的部署，平均排队长度相对历史人工操作降低 10.4%。
- 可解释与轻量：代理策略（决策树等可审计模型模仿 RL）、程序化策略、资源感知控制、边缘 RL 与数字孪生—边缘—云协同框架。
- **证据解读须谨慎**：上述「部署」多为带认证约束的在线控制 / 影子或建议模式，与「全自主接管路口」不是同一强度的结论；宣称落地的报道应追问控制权限、安全联锁与人工介入比例。

## 五、共性空白与争议

1. **真实部署仍是最大缺口**。CMU 2022 年 *The Real Deal*（arXiv:2206.11996）指出 160 篇 RL-TSC 论文中 67% 未说明真实数据来源、仅 1.8% 考虑公交 / 应急车辆等非私家车、仅 1 篇考虑行人，并归纳检测不确定性、通信可靠性、合规与可解释性、异构道路使用者四类挑战。到 2026 年，Springer 系统综述仍把 sim-to-real 与标准化 benchmark 缺失列为核心空白。2025–2026 年虽有 Traffic-R1、Traffic-VL 的试点量化结果，但属少数且多为约束式在线控制。
2. **指标不可比**。延误、排队、通行量的定义与统计窗口不一致，随机种子与需求实现次数常不报告；跨论文直接比较「降低 X% 延误」不可靠，只能当量级参考。优先看同一综述内统一口径整理的表格，或检查是否与 CoLight / PressLight / Max-Pressure 在同一设置下对比。
3. **「最新」不等于「最有效」**。多篇综述指出：在统一基准下，结构简单的压力类方法与精细调优的 DQN 仍具竞争力，复杂模型常缺少公平基线。
4. **仿真与路网偏置**。SUMO / CityFlow 占绝对多数，基准城市集中在杭州、济南、纽约、摩纳哥、卢森堡；这有利于复现，却限制了对跨城泛化与真实迁移的评估。LemgoRL 等包含真实路网、多类型使用者与运行约束的基准仍是少数。
5. **车辆中心与效率单目标**。行人、自行车、公交、应急车辆、公平性长期被低估；2025–2026 年开始改善，但尚未成为默认评价项。
6. **复杂度—实时性张力**。模型参数量从百万级走向 3B / 8B，而路侧边缘设备要求毫秒级推理与可审计性；轻量化、蒸馏、规则兜底因此成为部署类工作的必要组成。
7. **安全缺乏理论保证**。约束 RL 与动作屏蔽多为经验性设计，缺少形式化的行为边界证明，这是交管部门审批的实际障碍。

## 七、如需继续深挖

1. **文献计量验证**：在 Scopus / WoS 以 `"traffic signal control" AND ("reinforcement learning" OR "deep reinforcement learning")` 检索 2021–2026，做关键词共现聚类，验证 H1–H6 各簇的此消彼长；中文侧以 CNKI 为辅助，注意 CNKI 硕士论文与综述在 2022–2023 年的高峰会干扰计量口径。
2. **基线复现**：跟 CoLight / PressLight / FRAP 官方代码库与 SUMO、CityFlow 基准，用统一随机种子与多需求实现，检验「新方法」在公平设置下的真实增益。
3. **落地追踪**：检索 `"traffic signal" AND ("field deployment" OR "pilot" OR "real-world implementation")`，重点看 *Transportation Research Part C*、*IEEE T-ITS* 上带真实路口数据的论文；这是 2026 年最稀缺也最有价值的一类证据。
